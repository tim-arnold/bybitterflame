# Leveling and Advancement

## XP and Level Up

- **XP needed to level up:** Current level × 10.
- XP **resets to 0** after leveling up.
- Maximum level: 10.

| Level | XP to Next Level | Talent Roll? | Specialization |
|-------|-----------------|-------------|----------------|
| 1 | 10 | No | Base class only |
| 2 | 20 | No | Base class only |
| 3 | 30 | Yes (2d6) | **Specialization unlocked** |
| 4 | 40 | No | — |
| 5 | 50 | Yes (2d6) | — |
| 6 | 60 | No | — |
| 7 | 70 | Yes (2d6) | — |
| 8 | 80 | No | — |
| 9 | 90 | Yes (2d6) | — |
| 10 | — (max) | No | — |

## On Level Up

1. **Roll HP:** Roll your class hit die + CON modifier (minimum 1). Add the total to max HP and current HP.
2. **Talent roll** (at levels 3, 5, 7, 9 only): Roll 2d6 on your specialization's talent table.
3. **New spells** (Casters only): Learn additional spells per the progression table below.
4. **Specialization** (level 3 only): The GM presents the specialization as a narrative moment.

### Hit Dice by Class

| Class | Hit Die |
|-------|---------|
| Fighter | 1d8 |
| Rogue | 1d6 |
| Caster | 1d4 |

**Knockers** add +1 max HP per level from Stone Blood (in addition to the hit die roll).

## Specialization (Level 3)

At level 3, the GM assesses the player's choices during levels 1-2 and presents a specialization as a narrative moment — a mentor appears, a power awakens, a guild recruits them.

| Base Class | Specialization | Emerges From... |
|-----------|---------------|-----------------|
| **Fighter** | **Knight** | Heavy armor, defensive play, protecting allies |
| | **Hunter** | Ranged weapons, tracking, wilderness awareness |
| | **Marauder** | Reckless aggression, dual-wielding, wild fighting |
| **Rogue** | **Thief** | Lockpicking, pickpocketing, larceny, urban focus |
| | **Assassin** | Poison, ambush, lethal precision, blade focus |
| | **Scout** | Stealth, survival, recon, wilderness focus |
| **Caster** | **Druid** | Healing spells, nature magic, growth/life themes |
| | **Sorcerer** | Destructive spells, dark magic, power-at-a-cost choices |
| | **Enchanter** | Illusion, charm, mind magic, scholarly approach |

### How to Read Signals (GM Guidance)

- Fighter → Knight: picks sword/shield, heavy armor, protects allies
- Fighter → Hunter: picks bow, favors ranged, tracks enemies
- Fighter → Marauder: dual-wields, charges in, reckless choices
- Rogue → Thief: picks locks, steals, urban exploration
- Rogue → Assassin: uses poison, ambushes, goes for killing blows
- Rogue → Scout: sneaks ahead, sets traps, wilderness navigation
- Caster → Druid: favors healing, nature spells, life-preservation choices
- Caster → Sorcerer: favors damage, dark spells, power-seeking choices
- Caster → Enchanter: favors illusion, charm, knowledge-seeking choices

### Against the Grain

The player can accept or reject the suggested specialization. If they choose a **different path** than the one suggested, they start with **1 permanent Toll point** (Casters) or a narrative complication (Fighters/Rogues). The magic — or the path — doesn't sit naturally in them.

For Casters, this means their Toll starts at 1 and can never go below 1. They're always a step closer to the edge.

### Specialization is Permanent

Once chosen at level 3, a specialization cannot be changed.

## Level-Up Procedure

**Trigger:** The GM does not award XP — the app handles all XP via the downtime screen. However, check at **session start**: if `XP: N/M` where N ≥ M, trigger the level-up sequence before doing anything else (this handles edge cases where the app couldn't complete the level-up).

Do NOT wait for the player to ask. The GM initiates this automatically.

### Steps

1. **Announce** the level-up with narrative weight — pause the action, describe a surge of hard-won experience.
2. **Increment level** by 1. Emit `"level": newLevel` in the gamestate block.
3. **Roll HP**: Roll the class hit die + CON modifier (minimum 1). Add the total to `maxHp`. Increase `hp` by the same amount.
   - Announce the roll with a `diceRolls` entry.
4. **Specialization** (level 3 only): Present the specialization as a narrative moment. Read the player's choices during levels 1-2 (spell usage, combat style, narrative decisions) to determine which path to suggest. When presenting the three paths, **clearly signal which one calls most strongly** based on past actions — describe it as a pull, a resonance, a recognition. For the other paths, note they are full of promise but feel less natural — the magic resists slightly, or the path demands something the character hasn't yet shown. Reference specific past choices (e.g. "Your hands remember the shape of every healing spell you've cast" or "The shadows have answered your call more than once"). Remind the player that choosing against their natural affinity costs 1 permanent Toll point (Casters) or incurs a narrative complication (Fighters/Rogues). Wait for the player's response before proceeding.
5. **Talent roll** (levels 3, 5, 7, 9): Roll 2d6 on the specialization's talent table. Apply the result. If it grants a stat bonus, emit the updated stat. Append the new talent to the `talents` array.
6. **Spells** (Casters only): Compare old vs new level in the progression table. If the new level grants additional spells, tell the player how many and of what tier they may choose — then wait for their choices before emitting the updated `spells` array.
7. **Reset XP to 0.** Emit `"xp": 0`.
8. **Emit all changes in a single gamestate block** (or two if spells/specialization require a player choice first):

```gamestate
{
  "characterUpdates": {
    "level": 3,
    "xp": 0,
    "maxHp": 18,
    "hp": 18,
    "talents": ["existing talent", "new talent from roll"]
  },
  "diceRolls": [
    { "name": "Level Up — HP Roll (d8)", "notation": "1d8", "rolls": [5], "modifier": 2, "total": 7 }
  ]
}
```

When emitting `talents`, always include the full array (existing talents plus the new one). When a talent grants a stat change (e.g., +1 STR), also emit the updated stat in `characterUpdates`.
