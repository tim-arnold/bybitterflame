## Something Happens! (d100)

Roll when the party is exploring, resting in a dangerous area, or when time passes.

| d100 | Event |
|------|-------|
| 1-5 | A torch flickers and goes out. |
| 6-10 | A distant scream echoes through the halls. |
| 11-15 | The floor is slick with moisture. DEX check or fall prone. |
| 16-20 | A cold draft extinguishes an unprotected flame. |
| 21-25 | The party finds old bones and rusted equipment. |
| 26-30 | A section of ceiling crumbles. DEX check or take 1d6 damage. |
| 31-35 | Strange writing on the wall, barely legible. |
| 36-40 | A locked door blocks the path. |
| 41-45 | The sound of dripping water leads to a small pool. |
| 46-50 | A foul stench fills the air. CON check or disadvantage for 1 round. |
| 51-55 | Footprints in the dust -- something passed here recently. |
| 56-60 | A hidden alcove contains a small stash (1d6 gp). |
| 61-65 | An old trap, already triggered and harmless. |
| 66-70 | The passage narrows. Large creatures must squeeze through. |
| 71-75 | A rat scurries across the floor. |
| 76-80 | The walls are covered in fungus. One variety glows faintly. |
| 81-85 | A previously mapped door is now open (or closed). |
| 86-90 | A strange echo makes the party's voices carry far. |
| 91-95 | A deep rumble shakes the ground for a moment. |
| 96-100 | Absolute silence falls for a long, unsettling moment. |

|------|-------|

| 6-10 | "The lord's advisor is secretly a warlock." |

| 26-30 | "There's a hidden passage in the castle dungeon." |

| 46-50 | "The forest is haunted -- no one who enters at night returns." |
| 51-55 | "A secret cult meets in the basement of the butcher's shop." |
| 56-60 | "The blacksmith's apprentice found a magic ring in the river." |
| 61-65 | "There's a bounty on a werewolf terrorizing the farmsteads." |
| 66-70 | "The old king's tomb was never looted -- but it's well guarded." |

| 76-80 | "The thieves' guild has eyes everywhere in this town." |
| 81-85 | "Something enormous lives in the lake." |

Note: Roughly half of rumors should be true, a quarter partially true, and a quarter false. Mark them when creating.
