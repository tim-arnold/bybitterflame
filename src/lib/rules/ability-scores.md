# Ability Scores

## The Six Abilities

| Ability | Abbr | Governs |
|---------|------|---------|
| Strength | STR | Melee attacks, melee damage, forcing doors, lifting, climbing, grappling, gear slots (carry STR score items, minimum 8) |
| Dexterity | DEX | Ranged attacks, initiative, AC (unarmored/light), stealth, acrobatics, picking locks, dodging |
| Constitution | CON | Hit points per level, death fate rolls (self-stabilize requires 14+), resisting poison/disease, holding breath, morale checks (for monsters) |
| Intelligence | INT | Spellcasting (spell save DC = 10 + INT mod), identifying magic, recalling lore, learning |
| Wisdom | WIS | Perception, insight, stabilizing dying allies (DC 16), detecting traps, resisting charm |
| Charisma | CHA | Reaction rolls, persuasion, intimidation, deception, leadership, bartering |

## Using Ability Scores

### Ability Checks

Roll **d20 + ability modifier** vs a Difficulty Class (DC) set by the GM.

| DC | Difficulty |
|----|-----------|
| 10 | Easy |
| 13 | Normal |
| 16 | Hard |
| 20 | Very Hard |
| 24 | Nearly Impossible |

### Advantage and Disadvantage

- **Advantage:** Roll 2d20, take the higher result.
- **Disadvantage:** Roll 2d20, take the lower result.
- They cancel each other out. Multiple sources of the same type do not stack.

### Stat Damage and Recovery

- Some effects deal stat damage (e.g., poison reduces STR).
- If any stat reaches 0, the character dies.
- All stat damage is recovered after a full rest.

### Stat Increases

- Talent rolls at odd levels (3, 5, 7, 9) may grant +1 to a stat.
- No stat can exceed 18 through normal means.
